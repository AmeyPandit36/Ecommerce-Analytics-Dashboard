Ask the dataset a question

This is a deterministic analytics engine, not a chatbot. Your question is matched to a set of query templates, each one runs SQL against data/ecommerce.db (built from the real Kaggle CSV) with your current filters, and the answer comes back with its evidence table, a chart, how it was computed and what it cannot see. If a question needs a column this dataset does not have, the analyst says so instead of guessing.

What it can answer
Each topic below is backed by its own SQL aggregate
Categories
revenue, conversion, AOV, ratings, ranking
Products
top / worst products, concentration, ratings
Customers
value ranking, segments and their thresholds
Payments
popularity, revenue share, abandonment
Discounts
correlation with purchase, conversion by depth
Journey
funnel counts, drop-off, device and channel effects
Time
peaks by day, week, month, season, weekday
Quality
row counts, missing values, duplicates, hashes
What it will refuse
Because the columns do not exist in data/Ecommerce.csv
Product names
only product_id integers are published
Category / payment names
encoded as integers, no decoding map
Cities & states
location is an encoded id (0-224)
Profit & margin
no cost column, so revenue is the ceiling
Returns & delivery
not part of this dataset
Demographics
no age or gender fields exist
Ad spend / ROAS
channel revenue only, no spend
Forecasting
single-year synthetic data, no trend claim
